# Telop Studio

GitHub Pagesで動作する、背景透過テロップ作成ツールです。

## 主な機能

- プレビュー上のダブルクリックによる直接編集
- 選択文字の色・太字・斜体・フォント・サイズ・二重縁取り変更
- YouTube向け中央下配置
- 複数テロップの追加・複製・削除
- 1920×1080透過PNGの個別保存／ZIP一括保存
- PNG・ZIP生成時の進捗率表示
- 設定プリセットのJSON保存・読み込み
- 顔アイコンの丸／四角、縦横の切り抜き位置、拡大率調整

GitHub Pagesだけで動作する、顔アイコン・部分装飾・二重縁取り対応のテロップ作成ツールです。サーバーやビルドは不要です。

## 使い方

`index.html`をブラウザで開くか、リポジトリをGitHub Pagesで公開してください。

## GitHub Pages

1. このフォルダのファイルをGitHubリポジトリへ追加します。
2. GitHubの `Settings → Pages` を開きます。
3. `Build and deployment` のSourceを `GitHub Actions` にします。
4. Actionsが完了すると公開URLが発行されます。

## 主な機能

- フォント追加、サイズ、太字、斜体、色、不透明度
- 内側・外側を別々に設定できる二重縁取り
- 影の色、濃さ、距離、方向、ぼかし
- 半透明背景、角丸、余白
- 文字間隔、行間、揃え、縦書き
- 最大横幅、自動改行、最大行数、自動フィット
- ドラッグまたはスライダーによる配置
- 縦動画用9:16セーフエリア
- 選択範囲のみの太字、斜体、文字色
- 顔アイコン
- プリセット保存
- 1920×1080背景透過PNG
